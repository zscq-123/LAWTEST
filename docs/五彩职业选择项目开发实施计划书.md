**从计划到落地：大屏互动测试 · 职业画像生成 · 体能培优推送 · 扫码带走 · 导师对接**

>
> 关联文件：《法学院迎新“五彩职业选择”活动项目计划书》——本计划书为该活动方案的开发实施版本。

## 一、项目概述

### （一）项目背景

迎新活动“五彩法途，筑梦未来”以法学五大就业方向（律师、法官、检察官、企业法务、AI伦理合规顾问）为载体，为新生提供沉浸式职业启蒙体验。本项目负责把活动方案中的“线上职业特质测试”真正做成可运行的产品。

### （二）项目目标

1. **大屏可测**：新生在迎新现场的大屏上完成测试，勾选最多10个特质词，系统即时生成职业画像。
2. **画像好看**：结果揭晓带夸张的动态特效，生成五色主题的专属职业画像。
3. **体能随行**：自动推送该职业的身体素质要求与大学四年锻炼计划，支持扫码保存到手机随时查看。
4. **导师衔接**：画像生成后展示对应实务导师信息与预约入口。
5. **可复用**：词库、画像、锻炼计划、导师信息全部数据化管理，每年更新内容即可复用。

### （三）建设原则

- **前后端分离**：Vue 前端负责交互与视觉，Spring Boot 后端负责业务与数据。
- **视觉统一**：全站遵循 Ant Design 设计规范，五职业色彩作为品牌扩展色接入主题。
- **配置驱动**：职业内容由后端数据管理，修改内容不改前端代码。
- **容器化交付**：Docker 打包交付，一键启动，支持活动现场离线运行。
- **先跑通再优化**：优先完成 P0 主流程，再迭代统计、管理与增强功能。

## 二、总体技术方案

### （一）系统架构（前后端分离）

```
┌───────────────── 展示层（Vue 3 + Ant Design Vue）─────────────────┐
│      大屏端（测试流程）           手机端（扫码报告页）             │
└──────────────────────────┬────────────────────────────────────────┘
                           │ HTTP / JSON（HTTPS）
┌──────────────────────────▼────────────────────────────────────────┐
│       应用层（Spring Boot）                                        │
│ 匹配引擎 ｜ 画像与报告生成 ｜ 二维码 ｜ 导师对接 ｜ 统计 ｜ 内容管理 │
└──────────────────────────┬────────────────────────────────────────┘
                           │ JDBC
┌──────────────────────────▼────────────────────────────────────────┐
│       数据层：MySQL 8（utf8mb4）＋ Redis（可选）                   │
└────────────────────────────────────────────────────────────────────┘

部署层：Docker 容器化（nginx 前端容器 ｜ app 后端容器 ｜ db 数据库容器）
```

### （二）核心流程

1. 新生在大屏端进入测试，勾选最多10个特质词。
2. 前端将勾选词提交后端，后端按加权规则计算匹配结果。
3. 前端播放匹配动画与揭晓特效，渲染五色主题职业画像。
4. 后端生成报告编号与二维码地址，手机扫码打开同一份报告。
5. 报告页展示体能方案与对应实务导师信息。

4. 报告页底部统一标注：“本结果为兴趣初步画像，仅供参考”。

## 五、核心算法设计（匹配引擎）

### （一）词库结构

每个职业15个特质词，其中5个标记为“核心词”（权重2分），其余10个为普通词（权重1分）。词库存于数据库，由后端接口提供。

### （二）计分规则

- 学生勾选最多10个词，后端对五个职业分别累加命中词权重。
- 得分最高的职业为**第一适配**，次高为**第二适配**。
- 两个职业并列最高时，同时展示并标注“双适配”。

### （三）匹配度计算

- 匹配度 = 该职业得分 ÷ 满分20分 × 100%（10个词全部命中核心词的理论最高分为20分）。
- 匹配度低于40%时提示“兴趣线索较弱，建议同时了解第二适配方向”。

### （四）兜底规则

- 勾选词少于3个时，提示“再多选几个词，结果会更准确”。
- 报告统一标注“本结果为兴趣初步画像，仅供参考”。
- 后端对勾选词数量、词库合法性做参数校验，非法请求返回统一错误响应。

## 六、视觉与动效规范（基于 Ant Design）

设计规范统一采用 **Ant Design**，前端组件使用 **Ant Design Vue**（v4）。五职业专属色彩作为品牌扩展色接入主题 Token，其余色彩、字体、间距、圆角、阴影、组件与动效全部遵循 Ant Design 官方规范。

### （一）色彩规范

#### 基础色板（Ant Design 官方）

| 色板 | 色值 | 用途 |
| --- | --- | --- |
| 主色 | #1677FF | 主按钮、选中态、链接、进度 |
| 成功 | #52C41A | 完成、通过状态 |
| 警告 | #FAAD14 | 提示、待处理状态 |
| 错误 | #FF4D4F | 错误、超限提示 |
| 主文字 | rgba(0, 0, 0, 0.88) | 标题、正文 |
| 次文字 | rgba(0, 0, 0, 0.65) | 说明文字 |
| 边框 | #D9D9D9 | 卡片、分割线 |
| 页面背景 | #F5F5F5 | 页面底色 |

#### 五职业品牌扩展色（接入主题 Token）

| 职业 | 色彩 | 色值 | 使用场景 | 对应 Token |
| --- | --- | --- | --- | --- |
| 律师 | 皓月白 | #F5F7FA | 主背景、卡片 | colorBgLayout |
| 法官 | 苍穹蓝 | #2E6BE6 | 主色、按钮、光效 | colorPrimary（职业主题） |

> 职业主题色仅在对应职业的画像、报告与特效场景启用；全局功能组件统一使用基础主色。文字与背景对比度不低于 4.5:1（WCAG AA）。

### （二）字体规范

- 字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。
- 字号阶梯：12（辅助）／14（正文）／16（强调）／20（页面标题）／24（大屏标题）／30、38（大屏主视觉）。
- 大屏场景按 1.2—1.5 倍放大字号，3—5 米外清晰可读。

### （三）间距与栅格

- 统一使用 8px 基准网格：4／8／12／16／24／32／48。
- 页面采用 24 列栅格；大屏按 1920 基准、手机端按 375 基准适配。

### （四）圆角与阴影

| 层级 | 圆角 | 阴影 |
| --- | --- | --- |
| 基础（按钮、输入框） | 6px | 无／1px 边框 |
| 卡片、面板 | 8px | 低档阴影 |
| 浮层、弹窗、二维码层 | 8—12px | 中高档阴影 |

### （五）组件规范（Ant Design Vue）

| 使用场景 | 组件 |
| --- | --- |
| 开始、提交、重新测试 | a-button（大屏使用大尺寸） |
| 特质词卡 | a-tag / a-checkable-tag |
| 已选计数 | a-statistic / a-badge |
| 匹配进度 | a-progress |
| 揭晓反馈 | a-result |
| 画像信息 | a-card + a-descriptions |
| 体能方案 | a-list / a-steps |
| 导师名片 | a-card + a-avatar + 二维码 |
| 报告弹层 | a-modal / a-drawer |
| 加载状态 | a-spin / a-skeleton |
| 提示信息 | a-alert / message / notification |

### （六）动效规范

- 遵循 Ant Motion 设计原则：自然、高效、克制；基础动效时长 0.2—0.4s。
- 缓动函数：`cubic-bezier(0.645, 0.045, 0.355, 1)`。
- 揭晓、粒子等品牌特效为“场景级动画”，叠加 Canvas 实现，帧率不低于 50fps，低配设备自动降级。
- 手机端减少动画数量与时长。

### （七）无障碍与性能

- 文本与背景对比度不低于 4.5:1；全部交互支持触控与键盘，焦点可见。
- 大屏端动画帧率不低于50fps，低配设备自动降级为简化动画。
- 前端资源压缩，组件按需引入，首屏打开不超过3秒（本地环境）。

## 附录B 匹配算法说明

- 每个职业15个词：5个核心词（2分）＋10个普通词（1分）。
- 勾选最多10词，对五职业分别累加得分。
- 最高分为第一适配，次高为第二适配；并列展示“双适配”。
- 匹配度 = 得分 ÷ 20 × 100%。
- 少于3词提示补充选择；报告统一标注“仅供参考”。
