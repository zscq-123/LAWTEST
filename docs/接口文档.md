# 后端接口文档

基础地址：`http://<host>:8080/api`；统一响应体：

```json
{ "code": 0, "message": "success", "data": { } }
```

`code=0` 表示成功；`400` 参数/业务错误；`404` 资源不存在；`500` 系统错误。

## 1. GET /api/careers

获取五职业及词库（含核心词标记）。

```json
{
  "code": 0,
  "data": [
    {
      "id": 1,
      "name": "律师",
      "colorName": "皓月白",
      "colorCode": "#F5F7FA",
      "slogan": "以法为盾，以理服人",
      "sortOrder": 1,
      "keywords": [ { "id": 1, "word": "思辨敏捷", "core": true } ]
    }
  ]
}
```

## 2. POST /api/matching

提交勾选词（1—10 个），返回第一/第二适配职业、得分与匹配度。

请求：

```json
{ "keywordIds": [1, 4, 5, 6, 8] }
```

响应 data：

```json
{
  "keywordIds": [1, 4, 5, 6, 8],
  "scores": { "1": 10, "2": 0, "3": 0, "4": 0, "5": 0 },
  "first": { "careerId": 1, "name": "律师", "colorName": "皓月白", "colorCode": "#F5F7FA", "slogan": "以法为盾，以理服人", "score": 10, "matchRate": 50 },
  "second": { ... },
  "tie": false,
  "tieCareerIds": [],
  "tip": null,
  "disclaimer": "本结果为兴趣初步画像，仅供参考"
}
```

说明：核心词 2 分、普通词 1 分，满分 20；`tie=true` 表示并列双适配；`tip` 在勾选少于 3 词或匹配度低于 40% 时给出引导提示。

## 3. POST /api/report

生成报告：保存测试记录与报告编号，返回完整报告（含二维码）。

请求：`{ "keywordIds": [...] }`

响应 data：

```json
{
  "code": "LW202608271200001234",
  "qrUrl": "http://localhost:5173/report/LW202608271200001234",
  "qrImage": "data:image/png;base64,...",
  "match": { ...同匹配结果... },
  "career": { "id": 1, "name": "律师", "colorName": "皓月白", "colorCode": "#F5F7FA", "slogan": "以法为盾，以理服人" },
  "profile": { "slogan": "以法为盾，以理服人", "strengths": ["..."], "improvements": ["..."] },
  "fitnessRequirements": [ { "id": 1, "careerId": 1, "seq": 1, "content": "..." } ],
  "fitnessPlans": [ { "id": 1, "careerId": 1, "yearStage": "大一·体能筑基", "content": "..." } ],
  "mentors": [ { "id": 1, "careerId": 1, "name": "张律师（示例）", "title": "执业律师 · 民商事诉讼方向", "contact": "微信：zhang-law-demo", "bookingUrl": "" } ]
}
```

## 4. GET /api/report/{code}

按报告编号查询完整报告（手机扫码打开），返回结构与 `POST /api/report` 一致。

## 5. GET /api/mentors?careerId=1

返回对应职业的导师列表。

## 6. POST /api/test-records

保存一次测试记录（统计用）。请求 `{ "keywordIds": [...] }`，返回：

```json
{ "recordId": 1, "resultCareerId": 1, "result": { ...匹配结果... } }
```

## 7. GET /api/stats/summary

统计汇总：

```json
{
  "totalParticipants": 128,
  "careerDistribution": [ { "careerId": 1, "name": "律师", "count": 30 } ],
  "topKeywords": [ { "keywordId": 1, "word": "思辨敏捷", "count": 88 } ]
}
```

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DB_HOST` | `localhost` | 数据库地址 |
| `DB_PORT` | `3306` | 数据库端口 |
| `DB_NAME` | `lawtest` | 数据库名 |
| `DB_USERNAME` | `root` | 数据库用户 |
| `DB_PASSWORD` | `lawtest123` | 数据库密码 |
| `FRONTEND_BASE_URL` | `http://localhost:5173` | 前端地址（二维码内容前缀） |
| `CORS_ALLOWED_ORIGINS` | `*` | 允许的跨域来源 |
| `SERVER_PORT` | `8080` | 服务端口 |
