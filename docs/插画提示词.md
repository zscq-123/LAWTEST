# 五大职业形象插画提示词

> 用途：大屏首页背景、结果揭晓动画与职业画像页装饰。
> 统一要求：现代科技感扁平插画；人物年轻、专业、有亲和力；背景使用职业专属色彩；画面**不出现任何文字**；16:9 横版，分辨率不低于 1920×1080。
> 可直接复制任意一条投喂给豆包、即梦、Midjourney、Stable Diffusion 等绘图工具，或交给设计同学人工绘制。

## 通用约束（每条提示词都附上）

```text
Use case: stylized-concept
Asset type: 16:9 wide hero illustration for a touch-screen kiosk
Style/medium: modern flat vector illustration, clean geometric shapes, subtle gradients, professional and friendly
Composition/framing: wide landscape 16:9, subject centered with generous background space for UI overlay
Lighting/mood: bright, optimistic, tech-driven
Constraints: no text, no letters, no watermark, no logos; young professional Chinese character, approachable
Avoid: photorealism, dark mood, clutter, tiny details that disappear at 1080p
```

## 生成后的使用建议

1. 生成后放入 `frontend/public/illustrations/`（文件建议命名 `lawyer.png` / `judge.png` / `prosecutor.png` / `legal.png` / `ai-ethics.png`）。
2. 在首页卡片背景、揭晓页与画像页通过 CSS 引用；大屏建议使用 1920×1080 原图，手机端可用同图裁剪。
3. 如工具支持，可同时生成一张五色主视觉海报用于现场展板。
