# “五彩法途，筑梦未来”项目提示词包

> 适用场景：把项目交给豆包、ChatGPT 或编程助手逐步开发。
> 使用建议：先发第 1 条总览让 AI 理解全局，再按模块分开发第 2、3、4 条；文案和插画可以并行交给豆包和绘图工具。

---

## 1. 总览提示词（先发这条，用于整体开发）

你是一名资深全栈工程师。请基于以下需求，搭建一个“法学院迎新·五彩职业选择”线上职业特质测评系统，并给出整体技术方案、工程目录结构和分模块开发计划。

【项目背景】学院迎新活动“五彩法途，筑梦未来”，聚焦法学五大就业方向：律师、法官、检察官、企业法务、AI伦理合规顾问。新生在迎新现场的大屏上，从 75 个特质词（每个职业 15 个）中勾选最多 10 个，系统匹配出适配职业，生成五色主题的专属职业画像，并推送该职业的身体素质要求和大学四年锻炼计划；报告支持扫码在手机上打开、保存、随时查看；报告页同时展示对应职业的实务导师信息与预约入口。

【技术栈】前端：Vue 3 + TypeScript + Vite + Ant Design Vue（设计规范采用 Ant Design，五职业主题色作为扩展 token）。后端：Spring Boot 3（Java 17）+ MyBatis-Plus + MySQL 8（Redis 可选）。部署：Docker + docker-compose + Nginx。

【核心功能】
1. 大屏端测试流程：首页 → 选词（最多10个，超限提示）→ 匹配动画 → 揭晓特效生成职业画像。
2. 画像页：职业名、匹配度、能力优势、短板建议、职业格言、能力雷达图。
3. 体能页：身体素质达标要求 + 大学四年阶梯式锻炼计划。
4. 扫码：后端生成报告编号与二维码，手机端打开同一份报告，支持保存长图与收藏。
5. 导师对接：报告页展示对应职业导师名片与预约入口。
6. 数据统计：记录测试记录，输出参与人数、职业分布、高频勾选词。

【匹配算法】每个职业 15 个词，其中 5 个核心词权重 2 分、10 个普通词权重 1 分；勾选最多 10 个词后，对五个职业分别累加得分，最高分为第一适配、次高为第二适配，并列展示“双适配”；匹配度 = 得分 ÷ 20 × 100%；勾选少于 3 个词时提示“再多选几个词，结果会更准确”；报告统一标注“本结果为兴趣初步画像，仅供参考”。

【视觉规范】遵循 Ant Design：主色 #1677FF，8px 间距网格，字号 12/14/16/20/24/30/38；五职业主题色：皓月白 #F5F7FA、苍穹蓝 #2E6BE6、中国红 #C8102E、琉璃紫 #7B5EA7、科创青 #12B5A5；大屏端字号按 1.2—1.5 倍放大；揭晓特效使用 CSS + Canvas，帧率不低于 50fps，低配设备自动降级。

【验收要求】内容全部配置化（存数据库，由后端接口提供）；前后端分离；Docker 一键部署且断网可用。

请先输出技术方案、目录结构和任务拆解，再按我的下一步指令逐个模块实现。

## 2. 前端提示词（Vue 3 + Ant Design Vue）

你是前端工程师。请基于以下要求，使用 Vue 3 + TypeScript + Vite + Ant Design Vue 开发“五彩职业选择”系统前端，设计规范采用 Ant Design。

【页面清单】
- 大屏端（1920 基准，触控操作）：
  1. 首页：活动主视觉、五职业入口、“开始测试”按钮。
  2. 选词页：75 个特质词卡（a-tag/a-checkable-tag），五职业按色彩区分，已选计数（a-statistic/a-badge），最多选 10 个、超限提示（a-message），选中词有光效反馈。
  3. 匹配动画页：五色赛道/能量柱竞速动画，等待后端接口返回后定格。
  4. 结果揭晓页：全屏粒子/光爆特效，职业标志性元素聚合成职业形象，配职业色标题。
  5. 职业画像页：a-card + a-descriptions 展示画像，ECharts 能力雷达图，含匹配度、优势、短板、职业格言；按钮进入体能方案和生成二维码。
  6. 体能方案页：身体素质要求列表 + 四年锻炼计划（a-steps/a-list）。
- 手机端（375 基准）：扫码报告页，读取报告编号调用接口渲染同一份报告，支持保存长图（html2canvas）与收藏。

【接口约定】RESTful，统一响应体 { code, message, data }；主要接口：GET /api/careers、POST /api/matching、POST /api/report、GET /api/report/{code}、GET /api/mentors?careerId=xx。所有职业内容从接口获取，禁止写死。

【主题】五职业主题色作为品牌扩展色，仅在对应职业画像与报告页启用；全局组件用 Ant Design 基础主色 #1677FF；通过 Ant Design Vue 的 theme token 配置。

【动效】基础动效 0.2—0.4s，缓动 cubic-bezier(0.645, 0.045, 0.355, 1)；揭晓特效 Canvas 实现，低配设备降级为简化动画。

请先搭建工程骨架（Vite + Vue3 + TS + Ant Design Vue + 路由 + axios + 主题配置），再逐个实现页面，并标注每个页面的文件路径。

## 3. 后端提示词（Spring Boot）

你是后端工程师。请使用 Spring Boot 3（Java 17）+ MyBatis-Plus + MySQL 8，为“五彩职业选择”系统开发后端服务，提供 RESTful API，统一响应体 { code, message, data }，并做好全局异常处理和参数校验。

【数据表】
- career（职业）：id、name、color_name、color_code、slogan、sort_order
- keyword（特质词）：id、word、core（是否核心词）
- career_keyword（职业-词关联）：career_id、keyword_id、weight
- profile（画像内容）：career_id、strengths（优势）、improvements（短板与建议）、slogan
- fitness_requirement（身体素质要求）：career_id、seq、content
- fitness_plan（四年锻炼计划）：career_id、year_stage（大一至大四）、content
- mentor（实务导师）：id、career_id、name、title、contact、booking_url
- test_record（测试记录）：id、selected_keywords、scores、result_career_id、created_at
- report（报告）：id、record_id、code（报告编号）、qr_url、created_at

【接口清单】
- GET /api/careers：返回五职业及词库（含核心词标记）
- POST /api/matching：入参 { keywordIds: [...] }，按“核心词2分、普通词1分”计算五职业得分，返回第一/第二适配职业、匹配度（得分/20×100%）、并列双适配与少于3词提示
- POST /api/report：生成报告记录、报告编号与二维码地址（ZXing 生成，二维码内容为报告页 URL）
- GET /api/report/{code}：按编号返回完整报告数据（画像、体能、导师）
- GET /api/mentors?careerId=xx：返回对应职业导师列表
- POST /api/test-records：保存测试记录（统计用）
- GET /api/stats/summary：返回参与人数、五职业分布、高频词（可选）

【要求】提供建表 SQL 和初始化数据 SQL，内容包含五大职业各 15 个特质词（核心词各 5 个）、画像文案、身体素质要求、四年锻炼计划，数据与《法学院迎新“五彩职业选择”主题活动》方案一致；接口必须做参数校验（选词数量 ≤10、词 ID 合法等）；代码分层 controller/service/mapper/entity，命名规范，附关键注释。

## 4. Docker 部署提示词

你是 DevOps 工程师。请为“五彩职业选择”系统编写 Docker 部署方案：

1. 前端 Dockerfile：使用 node 构建 Vue 3 项目，产物放入 nginx:alpine，配置 gzip 和 SPA 路由。
2. 后端 Dockerfile：Spring Boot 项目多阶段构建（maven 打包 → JRE 运行）。
3. nginx.conf：静态资源服务 + 将 /api 反向代理到后端容器。
4. docker-compose.yml：包含 nginx、app（Spring Boot）、db（mysql:8，带数据卷持久化）三个服务；数据库连接使用服务名；生产配置通过环境变量注入（SPRING_PROFILES_ACTIVE、DB_URL、MYSQL_ROOT_PASSWORD 等）。
5. 离线部署说明：docker save/docker load 打包镜像的步骤，以及现场无网络时一键启动的命令。
6. 提供启动脚本（start.sh / start.bat）和一页部署手册。

要求：compose 文件可直接运行，配置注释完整，满足迎新现场断网可用。

## 5. 内容文案生成提示词（豆包 / ChatGPT 等）

### 5.1 职业画像文案

你是高校职业规划师。请为“律师、法官、检察官、企业法务、AI伦理合规顾问”五个法学职业各生成一份职业画像文案，输出 JSON 格式。每份包含：slogan（一句职业格言，有力量、贴合职业）、strengths（3—5 条性格与能力优势，来源于该职业特质词）、improvements（3—4 条潜在短板与提升建议，语气积极）。语言面向大一新生，通俗、正向、不空泛。特质词参考：律师（思辨敏捷、逻辑缜密、善于沟通、抗压坚韧等）；法官（公正无私、严谨审慎、敬畏规则等）；检察官（立场坚定、敢于担当、恪守正义等）；企业法务（风控敏锐、合规审慎、统筹协调等）；AI伦理合规顾问（创新思维、敬畏科技、跨界融合等）。输出可直接写入数据库的 JSON。

### 5.2 大学四年锻炼计划

你是高校体育教师。请为五个法学职业各制定一份“大学四年阶梯式体育锻炼计划”，按大一（体能筑基）、大二（专项强化）、大三（职业场景模拟）、大四（达标冲刺）四阶段编写，每阶段 2—3 条具体建议（运动项目、每周频次、强度、注意事项），结合职业特点：律师（伏案久坐、肩颈与耐力）、法官（连续庭审久坐久站、体态）、检察官（外勤取证、心肺与体能）、企业法务（商务形象、精力管理）、AI伦理合规顾问（长期电脑办公、颈椎与视力）。同时输出每个职业的 4 条“身体素质达标要求”。文末统一加一句“本内容为通识性建议，非医疗意见；如有健康问题请遵医嘱。”输出 JSON 格式。

### 5.3 现场导师对接话术

你是活动主持人。请为“五彩职业选择”迎新活动写一段现场引导话术（面向新生，时长约 1 分钟）：说明测试怎么做（大屏勾选 10 个词）、生成画像后会推送体能方案、扫码带走报告、以及可以到“导师面对面”交流区找对应职业的实务导师聊聊。语气热情、简洁、有感染力，适合现场扩音播报。
