# 五彩法途 · 全部页面设计稿

法学院迎新活动「五彩职业选择」测评系统全量界面设计稿（8 个页面），视觉语言遵循
Ant Design，深色科技风 + 玻璃拟态；文案、职业数据、特质词库、体能方案、导师信息均
取自系统真实数据（`sql/02_data.sql`）。

## Pixso 文件版本（当前交付）

Pixso MCP 连接后，8 个页面已**直接生成在 Pixso 文件「页面 1」画布**中（非图片导入，全部为可编辑图层）：

- 画布按 `01-首页 … 06-体能赋能` 横排（每屏 1920×1080），`07-手机报告长页`（390×2400）与 `08-我的收藏`（390×844）在其下方。
- 设计变量：变量集「五彩法途」，60 个 token（底色/文字/品牌色/五职业色/字号/间距/圆角/字体）。
- 组件均由框架 + 文本 + 图标（lucide）原语构建；能力雷达图为 SVG 矢量；五职业意象使用天平/法徽/盾牌/合同/芯片等图标。
- 字体：Pixso 环境内 PingFang SC 不可用，已统一使用等宽中文无衬线替代字体 Noto Sans SC（变量 `$font_main`），如需改回可全局替换。
- 布局经 `check_layout` 校验无问题；关键像素抽样与 8 张截图（`preview/pixso/shots/`）完成视觉核验。

> 同目录另有等画布尺寸的 HTML/CSS 版本（`pages/*.html` 与 `preview/*.png`），与 Pixso 版数据一致，可作为还原/比对底稿。

## 设计系统

### 色彩

- 背景：`#060D1A → #0B1220` 深蓝黑渐变，四角五色光晕（透明度 14%–22%）+ 56px 半透明白网格（四周渐隐）。
- 玻璃面板：白色 4% 半透明底、1px 白色 14% 边框、14px 圆角。
- 主操作色 `#1677FF`；成功 `#52C41A`；警告 `#FAAD14`；错误 `#C8102E`。
- 五职业色（全站一致）：

| 职业 | 颜色名 | 色值 | slogan |
| --- | --- | --- | --- |
| 律师 | 皓月白 | `#F5F7FA` | 以法为盾，以理服人 |
| 法官 | 苍穹蓝 | `#2E6BE6` | 法平如水，公正如一 |
| 检察官 | 中国红 | `#C8102E` | 恪守正义，敢于亮剑 |
| 企业法务 | 琉璃紫 | `#7B5EA7` | 行稳致远，合规制胜 |
| AI伦理合规顾问 | 科创青 | `#12B5A5` | 科技向善，规则先行 |

### 字体与层级

- 字体：PingFang SC / Microsoft YaHei。
- 主标题 44–72px / 800；区块标题 20–32px / 600；正文 16–18px；辅助 12–14px（透明度 50%–72%）。
- 间距按 4px 倍率；圆角 6 / 10 / 14px；按钮胶囊 999px；卡片阴影 `0 4px 12px rgba(0,0,0,0.4)`。

### 公共组件

- 四步流程步骤条：勾选特质 → 匹配职业 → 揭晓画像 → 扫码保存（首页未开始 / 选择第 1 步 / 匹配第 2 步 / 揭晓第 3 步高亮）。
- 职业头像：职业色渐变圆角方块 + 职业图标 + 同色光晕；职业插画用于首页卡片、揭晓背景、画像 Hero、体能侧卡。
- 免责声明：兴趣初步画像页统一为「本结果为兴趣初步画像，仅供参考」；体能页追加「本内容为通识性建议，非医疗意见；如有健康问题请遵医嘱。」

## 渲染与校验

```bash
node render.mjs    # 重新渲染全部 PNG（需本机 Edge；默认 1920/390 等画布尺寸）
node verify.mjs    # 布局校验：越界 / 文本溢出 / 控件重叠
node check-points.mjs  # 关键控件像素颜色抽样
```

渲染与校验依赖 `frontend/node_modules/puppeteer-core` 与本机 Edge 浏览器。
