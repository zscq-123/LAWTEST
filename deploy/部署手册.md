# “五彩法途，筑梦未来”系统部署手册

## 一、架构

| 容器 | 镜像 | 职责 |
| --- | --- | --- |
| nginx | lawtest-frontend（自构建） | 前端静态资源 + `/api` 反向代理 |
| app | lawtest-backend（自构建） | Spring Boot 后端（8080） |
| db | mysql:8.0 | 数据库（数据卷持久化） |

首次启动数据库容器时，会自动按顺序执行 `sql/01_schema.sql`（建表）与 `sql/02_data.sql`（初始化内容）。

## 二、在线部署（开发机/有网环境）

前置要求：Docker Engine 20.10+ 与 Docker Compose v2。

```bash
cd deploy
docker compose up -d --build
```

启动完成后浏览器访问 `http://localhost`（大屏端），手机扫码即可打开报告页。

常用命令：

```bash
docker compose logs -f      # 查看日志
docker compose down         # 停止（保留数据卷）
docker compose down -v      # 停止并清空数据库数据（慎用）
```

## 三、现场离线部署（断网可用）

### 1. 在有网环境提前制作离线镜像

```bash
cd deploy
docker compose build
docker save mysql:8.0 lawtest-backend:latest lawtest-frontend:latest -o lawtest-images.tar
```

### 2. 现场导入并启动

```bash
docker load -i lawtest-images.tar
cd deploy
FRONTEND_BASE_URL=http://<现场电脑IP> docker compose up -d --no-build
```

大屏浏览器全屏打开 `http://<现场电脑IP>`；二维码内容默认指向 `http://<现场电脑IP>/report/<编号>`，扫码后手机需与现场电脑处于同一局域网。

## 四、环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `HTTP_PORT` | `80` | 对外访问端口 |
| `DB_PORT_EXPOSE` | `3306` | 数据库对外映射端口（与本地 MySQL 冲突时修改） |
| `DB_PASSWORD` | `lawtest123` | 数据库 root 密码（生产务必修改） |
| `FRONTEND_BASE_URL` | `http://localhost` | 二维码内容前缀，现场改为实际访问地址 |

示例（Windows PowerShell）：

```powershell
$env:HTTP_PORT=8088
$env:FRONTEND_BASE_URL="http://192.168.1.15:8088"
docker compose up -d --build
```

## 五、数据备份与恢复

备份：

```bash
docker exec lawtest-db sh -c 'exec mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" lawtest' > lawtest-backup.sql
```

恢复：把备份文件导入容器后执行 `mysql -uroot -p lawtest < lawtest-backup.sql`。

## 六、常见问题

| 问题 | 处理 |
| --- | --- |
| 数据库初始化后想重跑 SQL | `docker compose down -v && docker compose up -d`（会清空数据） |
| 现场无网络无法拉镜像 | 按第三节提前 `docker save` 离线包 |
| 二维码手机扫不开 | 确认 `FRONTEND_BASE_URL` 为现场电脑局域网 IP，且手机可访问该地址 |
| 端口被占用 | 设置 `HTTP_PORT` / `DB_PORT_EXPOSE` 后重启 |
| 内容更新 | 直接改数据库（后端内容全部配置化，无需重新发版） |
